Codierung der Ziffern

Die Ziffern im GTIN-Barcode können auf drei unterschiedliche Arten codiert werden:

  • A-Codierung: Standard-Codierung für den linken Block
  • B-Codierung: Invertierte A-Codierung für den linken Block
  • C-Codierung: Immer für den rechten Block verwendet

Die erste Ziffer wird nicht codiert. Stattdessen werden die A/B-Codierungen im linken Block für jede Ziffer anders belegt, damit das Lesegerät die korrekte Leserichtung erkennen kann.

Prüfziffer

Die letzte Ziffer des GTIN-Codes ist die Prüfziffer. Sie wird berechnet, indem die ersten 12 Ziffern abwechselnd mit 1 und 3 multipliziert und addiert werden. Die Prüfziffer wird so gewählt, dass das Gesamtergebnis durch 10 teilbar ist.

Beispiel: 4×1 + 0×3 + 0×1 + 0×3 + 0×1 + 0×3 + 0×1 + 0×3 + 0×1 + 0×3 + 0×1 + 0×3 = 4

Prüfziffer = 10 - (4 % 10) = 6

Ländercode

Die ersten zwei bzw. drei Stellen geben das Land an, das die GTIN vergeben hat:

  • 40-43, 440: Deutschland
  • 978: ISBN (Bücher)
  • Weitere: Verschiedene Länder weltweit

Die nachfolgenden Stellen sind der Herstellercode und eine hersteller-interne Nummer.

Barcode-Struktur

Ein EAN-13 Barcode besteht aus:

  • Start-Muster: 3 Module (längere Balken)
  • Linke Seite: 6 Ziffern à 7 Module
  • Mittleres Trennzeichen: 5 Module
  • Rechte Seite: 6 Ziffern à 7 Module
  • End-Muster: 3 Module

Gesamt: 3 + (6×7) + 5 + (6×7) + 3 = 95 Module

GTIN-Datenbank

In der GTIN-Datenbank können Sie nach einem bestimmten GTIN-Code bzw. nach einem Produkt suchen.

Hinweis: Dies bedeutet nicht, dass die Ware auch dort hergestellt wurde. Es heißt nur, dass der Hersteller den Code in diesem Land beantragt hat.
